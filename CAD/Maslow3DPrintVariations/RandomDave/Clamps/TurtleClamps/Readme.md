## Item

Stiffened replacement clamp for the Maslow.


## Designer

https://forums.maslowcnc.com/u/randomdave


## Compatibility

Maslow 4.0 / 4.1


## Description

A 20mm thick clamp design with no split for added stiffness, direct replacement for the stock clamps.

If in doubt, print 2 x StandardClamp.stl and 8 x ClampInserts.stl, with 5 layers top and bottom, 3 wall loops and 30% cubic infill.

https://forums.maslowcnc.com/t/turtle-clamp-non-split-clamp-design/25420

## Hardware required
### Standard conversion, with 2 clamps, assuming re-use of standard Maslow4 posts:
* 28 x 16mm cap head M3 screws.
* 8 x M3 hammerhead (t-nut) nuts for 2020 profile.
* 8 x 10mmx2mm plate washers (or 8x1mm)

### More detailed, per-clamp requirements:
* 4 x 14mm or 16mm cap head M3 screws for the inserts - anything up to 20mm should work but the head of the screw might poke out.
* 4 x M3 hammerhead (t-nut) nuts for 2020 profile.
* 4 x 10mmx2mm plate washers (or 8x1mm)
* 12 x 15+mm cap head screws (to attach posts). Exact length depends if you're using nylock nuts, and whether you're re-using the standard posts or printing those.

## Variants

There are some variants included in '/Variants' as part of ongoing development / testing:
  * NoBaseCutoutClamp - doesn't have the cutouts for getting the router as flat to the base as possible. Can still be used as a Top or Base clamp.
  * Top-NoBaseCutoutNoZCutoutClamp - has no cutouts that aren't needed for a Top Clamp - can only be used for the top.
  * Base-HexReinforcedClamp - Has some extra re-inforcement that only works for a Base Clamp (the motors would foul if it was a Top).
  * Base-SolidReinforcedClamp - As HexReinforced, but solid. 

## Version History

### 1.1 Update

* The depth of the bolt area has been standardised so they all use 10mm of bolt-thread. 
  * This means 15+mm bolts will work if re-using the standard posts, 25mm with some other of my designs.
  * Which in turn means a conversion of only the clamps just needs 28 x 16mm cap head screws.
